# Architecture

React/TypeScript/Vite/Tailwind provides the dark Frosted Folder Lookbook landing experience (`/`), 3-column studio workstation (`Your media` bin, prominent 9:16 preview stage with scrubber/fullscreen transport, `Voice Director` + `Text`/`Audio`/`Look`/`Trim`/`AI Ad` inspector), live 16 kHz PCM `AudioWorklet` WebSocket streaming (`frontend/public/pcm-processor.js` + `hooks/useRecorder.ts`) with `MediaRecorder` fallback, 3-track interactive timeline with clip thumbnails and quick track actions, and HTML5 `<video>` playback. FastAPI serves the compiled UI, `/api`, and `/ws/voice/{project_id}` from a single container.

JSON project files are atomically replaced under UUID directories (`/data/projects/<uuid>`). Photos are decoded, EXIF-normalized, and fitted without stretching (`contain` or `cover`). Uploaded videos (MP4/MOV/WebM) are probed with `ffprobe`, optionally trimmed (`trim_start`/`trim_end`), fitted to 720×1280, and optionally mixed with background music via `amix` + `anullsrc` when `keep_clip_audio` is enabled.

Speech uses a Dual-ASR CPU router (`DualSpeechRouter` in `backend/app/speech.py`) combining:
- **Pass A (`IndicConformerTamilEngine`)**: AI4Bharat IndicConformer Tamil INT8 ONNX via `sherpa-onnx` (`OfflineRecognizer.from_nemo_ctc`, greedy decoding, CPU).
- **Pass B (`FasterWhisperSpeechEngine`)**: `faster-whisper` `small` model, CTranslate2 CPU INT8, with a Tanglish domain `initial_prompt`, silence/RMS energy gate (`>= 0.3s`, `RMS >= 0.004`), and primer-leak guard.
In `tanglish` mode both passes decode the same in-memory 16 kHz `float32` buffer sequentially under a shared `asyncio.Lock()`. `ta` mode routes to IndicConformer-TA and `en` mode routes to Whisper `small` (`initial_prompt=None`). Initialization runs off the HTTP startup path; `/api/capabilities` exposes per-engine readiness (`asr_engines: { indicconformer_ta, faster_whisper_small }`). Missing models degrade gracefully; no fake transcript fallback exists.

The deterministic parser (`backend/app/parser.py`) preserves raw transcripts separately, normalizes Unicode NFC and Tamil-script loanwords (`போட்டோஸ்`, `ரீல்`, `மியூசிக்`, `ஆஃபர்`, `கடைசில`, `கம்மி`), applies `rapidfuzz` recovery (`ratio >= 82`) strictly to unquoted Latin action tokens, and fuses Pass A + Pass B operations in `parse_dual_command(...)` across 1–5 uploaded media items without fabricating confidence percentages.

One FFmpeg render runs at a time (`render_gate`). FFmpeg receives argument arrays without shell evaluation (`subprocess.run(..., check=False)`). Pillow/`libraqm` shapes Tamil overlays into PNGs using Noto Sans Tamil. Successful renders commit a new revision; failures preserve the previous state. Undo restores settings, asset order/trims, edit history, and the already-rendered MP4 revision without recompression (up to 10 snapshots retained). Jobs are process-local.

Optional cloud advertisement generation (`backend/app/generation.py`) targets Google's `gemini-omni-1.2-flash` Interactions REST endpoint (`POST https://generativelanguage.googleapis.com/v1beta/interactions`) with `x-goog-api-key`, explicit `aspect_ratio`/`duration` schema, bounded timeouts, and async background job polling. Without `GEMINI_API_KEY`, the API returns `"Key not set"` and core local editing remains fully operational.

Alternatives: AI4Bharat IndicConformer offers Tamil recognition but a heavier integration. Bodhan Indic-Transcribe targets code-mixed transcription and requires separate model/license evaluation. BHASHINI hosted adapters require credentials and connectivity. None is a P0 dependency. See [PITCH_SOURCES.md](PITCH_SOURCES.md) for sources accessed 27 November 2026.
