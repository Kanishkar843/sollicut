# Optional Gemini advertisement generation

The landing page uses the supplied Frosted Folder Lookbook component, customized for SolliCut with locally bundled 3:4 campaign cards across retail, floristry, food, and beauty sellers.

The local studio editor accepts 1–5 photos (JPEG/PNG/WebP) and video clips (MP4/MOV/WebM), displays a dark workspace with preview transport, `Your media` library, 3-track timeline, and functional `Text`, `Audio`, `Look`, `Trim`, and `AI Ad` inspector tabs. Video clips can be trimmed (`trim_start`/`trim_end`), reordered, fitted (`contain` or `cover`), and mixed with original clip audio (`keep_clip_audio`) alongside background music.

The separate `AI Ad` panel records the real microphone, transcribes locally, lets the user review/edit the prompt, pick duration (`3–15s`, capped at `3–10s` when 2 reference photos are selected per Omni interpolation rules) and up to 2 reference photos, and requires explicit confirmation to call Gemini. Without `GEMINI_API_KEY` on the server, the UI clearly shows **Key not set** and keeps ordinary local editing completely keyless. Set `GEMINI_API_KEY` in an untracked root `.env` and recreate Compose to enable cloud generation (`SOLLICUT_VIDEO_MODEL` defaults to `gemini-omni-1.2-flash`). Never place keys in frontend code or commit `.env`.

Adapter implemented against Google's REST Interactions documentation (`https://aistudio.google.com/docs/omni.md`, inspected 27 November 2026; older Veo preview models shut down per `https://aistudio.google.com/docs/video`). Requests pass `x-goog-api-key`, use `response_format: {type: "video", aspect_ratio, duration}`, run inside a bounded background job (`/api/jobs/{id}`) that prevents concurrent edit races, probe the output MP4 before committing a revision, add the generated clip to `project.assets` for follow-up edits, and preserve undo and previous outputs on failure.

**Honesty note:** No Gemini API key has been supplied and no live cloud generation has been executed. Mocked REST and job-lifecycle tests verify the adapter contract only; provider access, billing, generation quality, and live output remain unverified until a key is supplied. Human microphone acceptance is also still required.
