- [ ] Typed project state and atomic local storage
- [ ] Deterministic multilingual parser and regression cases
- [ ] FFmpeg renderer, shaped overlays and generated demo assets
- [ ] Validated uploads, jobs, revision history and undo
- [ ] Voice-first React interface and real MediaRecorder
